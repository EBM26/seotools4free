how to add schema markup to wordpress without plugin?

You can add schema markup to WordPress without a plugin by placing a JSON-LD script in the theme template, a child theme, or a controlled custom-code area. A child theme is preferable because direct edits to a parent theme can disappear after updates. A practical way to use this is to begin with the page’s audience and intent, then check the result in the actual site and in a validation tool. Do not add information merely to satisfy a checklist. Search engines and readers both benefit when the markup, wording, and page experience agree. Before publishing, review the source code, test important URLs, and look for warnings rather than assuming that a green score means the work is finished. It is also wise to document what was added, who owns it, and when it should be reviewed. That makes future redesigns, migrations, and content updates much less risky. For a real project, the best final check is to compare the result with the original goal, test a few realistic cases, and revise anything that feels forced or misleading. A clear implementation is usually more durable than an elaborate one.
