How do i find utm source in ga4?

To find UTM source data in Google Analytics 4 (GA4), go over to the left-hand navigation menu, click on **Reports**, and expand the **Acquisition** section. From there, select **Traffic acquisition** (or User acquisition for first-visit data). By default, the main table displays traffic grouped by primary channel groups. To isolate the UTM source, click the drop-down arrow above the first table column (where it says "Session primary channel group") and switch the dimension to **Session source** or **Session source / medium**. This will display a detailed breakdown showing exact UTM source values like `newsletter`, `facebook`, or `google`. If you want to analyze specific campaigns, click the blue `+` icon next to the primary dimension column to add a secondary dimension, such as **Session campaign**, allowing you to cross-analyze traffic, engagement rate, and conversions by source.
